🔐 Connect Kalshi

Link your own Kalshi account to KalBot. Use a key made just for KalBot so you can revoke it any time.

Open this from Telegram.

In the KalBot chat, type /connect and tap “🔐 Connect Kalshi”.

1Create an API key on Kalshi

On kalshi.com: Account → API keys → Create key. Kalshi shows a Key ID and gives you a private key file (it lands in your Downloads / Files).

2Key ID
3Private key

Pick the key file, or paste the whole key text.

Your key goes straight to the KalBot chat through Telegram, where it is checked with Kalshi and stored encrypted. It never appears in the chat, and this page saves nothing.
